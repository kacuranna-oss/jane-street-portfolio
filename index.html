Yandex Cup ↗

Lead designer & art director · concept, web, logo system · 2024

An open programming championship. I turned its audience research into a radically plain, code-like identity — and defended it.

01Brief

// project
Yandex’s open championship for developers: six tracks, from juniors to experts, with an offline final.
// objective
A flexible, recognisable visual language: every year looks different but reads as one series.
// challenge
Speak to very different people — curious beginners and olympiad veterans — who instantly spot fake “tech” design.

02My part

// role
Lead designer and art director, author of the concept.
// i made
Audience research (interviews with developers → four archetypes), visual research, four concepts and their copy, the main website page and its animation, the logo constructor. A second designer did resizes; Yandex developers built the site from my files, and I reviewed every step.
// key decision
Push the most radical direction — Ultra Clarity, a protest against decorative design. It wasn’t accepted at first; I had to argue that this audience values precision over polish.

03Craft

// four directions, four type principles
Each concept was shown as a live website, not a moodboard.

// final
The logo is code: { Y A N D E X | C U P }. Highlighter marks instead of buttons; facts linked by dotted connectors like a graph; text “decodes” into place like terminal output.
// logo constructor
Y · cup · C, each with variants — coordinate axes, a trophy, a Java mug, °C. A small puzzle for people who like puzzles.

04Result

// outcome
The system has run since 2024 — web, merch, offline — and another team kept extending it after I left. Applications roughly doubled, as part of a wider campaign.
// what worked
Developers read the language as their own.
// what i’d improve
Make the site fully code-native and more personal — adapting to each participant’s track and level.

Yandex for Developers

Art director · v1 2021, rebrand · brand system for 40+ events

A brand for Yandex’s developer community where code is not illustration but the typesetting rule. Its logo — a piece of code — survived a full rebrand.

01Brief

// project
Yandex’s platform for the IT community: 40+ conferences, meetups and parties across eight stacks — backend, frontend, mobile, ML and more.
// objective
One brand flexible enough for any event, with a character for each stack.
// challenge
v1 was born during COVID for streams and social media. The rebrand had to scale to offline events and many teams — and keep the */ sign the community already liked.

02My part

// role
Art director; author of the v1 idea and the rebrand concept.
// i made
v1: key idea, pitch, key visual, the */ logo and the typeset wordmark. Rebrand: the scalable system and the main key visual. Agency Shchuka developed and adapted it under my direction; Yandex developers built the graphics generator.
// key decision
Make the logo a piece of code: */, the end of a comment — and a “Y”. The rebrand brief explicitly required keeping it.

03Craft

// design decision
Syntax as a typesetting rule. Every part of a title ends with a red semicolon: ML Conf; Moscow; 07.09;
// rules, not taste
Logo size = headline size ÷ 1.25. Margin = half the x-height, measured on flat glyphs. Leading 100%. Dash = stroke × 3. Four lines max. Anyone can build a correct layout without an art director.
// graphics by event type
Generative lines for conferences, abstract 3D for meetups, pixel stickers for informal events. Background colour = stack. Typeface: YS Geo.

04Result

// outcome
One system across 40+ events in Moscow, Belgrade, Yerevan and online. The */ became a brand asset.
// what worked
Rules written as formulas let the brand scale without constant art direction.
// what i’d improve
Automate even more — the rules are already formulas. And after years in use, research how the audience reads the brand and strengthen what matters to them.

YaTalks 2021

Concept author & art director · identity, logo, stage

Yandex’s flagship tech conference under the theme “IT is the new space”. I avoided every space cliché: no rockets, no stars.

01Brief

// project
A three-day marathon with ~100 speakers and six tracks, online and offline; the main day ran on about nine stages.
// objective
From Yandex’s brief: reinforce its image as an IT leader, support hiring, get closer to Gen Z.
// challenge
One identity for six tracks, a hundred speakers, the broadcast and the physical venue.

02My part

// role
Author of all initial concepts and the logo; art director of the system.
// i made
Three concepts and six logo options in two weeks; the final logo; stage sketches, often by hand; materials. I defended the concept to internal stakeholders. Agency Shchuka built the generative graphics, animation and resizes under my direction.
// key decision
Space as the interaction of objects — forms that attract, collide and merge, the way ideas do at a conference.

03Craft

// design decision
Living gradient forms + a strict modular grid (frames split 1/2 to 1/6) + a monospace “telemetry” voice. Each track got its own colour space.
// type
CoFo Sans and CoFo Sans Mono: a sturdy grotesque with moderately closed apertures — less soft than a humanist sans, less cold than a geometric one. Native Cyrillic, and a mono sibling in the same family.
// stage
Gradients printed on acrylic, fading to zero opacity — the digital blur dissolved into the real venue.

04Result

// outcome
The YATALKS wordmark outlived the 2021 identity and is still in use. I kept evolving YaTalks each year; the 2023 ASCII-art direction landed well.
// what worked
One system covered the site, broadcast, merch and stage.
// what i’d improve
A more functional site with simpler registration — it leaned too far into art. And less red, more white: white as space, for a calmer, more open place to talk.

Yandex Welcome Pack

Concept author · merch system, product design, production · 2024

Merch as a construction kit: every item clips onto every other. Shown here through one case — the pack every new Yandex employee receives.

01Brief

// project
The welcome pack for every new Yandex employee. Print run: 10,500+.
// objective
Reflect the shared HR brand and leave room for each business unit to customise.
// challenge
Merch kept multiplying, it was hard to defend beyond taste — and people didn’t always wear it.

02My part

// role
Author of the concept; led the welcome pack from idea to production.
// i made
I first defended the idea with a New Year backpack — “item zero”. For the welcome pack I found an independent maker of outdoor bags and briefed him on the carabiner idea; he built the prototype and transferred the rights. I placed the branding and made master files; a factory made the patterns; production ran in China.
// key decision
Stop making one-off merch. Every piece works alone and clips onto past and future collections.

03Craft

// design decision
The shared code is the connection, not the logo: loops, carabiners, paracords. Bottles with carabiners, T-shirts with small loops for a pass or badge, even pens with loops. Like a charm bracelet — collect and recombine.
// technical
Materials chosen by task and budget (e.g. jacquards). Print areas and re-cuts agreed with each factory. Screen print with colour separations, direct print, debossing on fabric, 3D embroidery.

04Result

// outcome
A bag with a detachable pouch in three colours, plus seven items chosen from newcomers’ feedback. The constructor became the principle for the collections that followed.
// what worked
The mechanic — it still works.
// what i’d improve
A tested materials spec: fabrics, webbing and hardware checked together, so every new collection starts from a proven base.

Mercuryo Decks

Project lead · presentation system, AI agents · with designer Dima

Instead of teaching people a template, I put the brand where they already work: ready slide types and AI agents.

01Brief

// project
A company-wide presentation system for Mercuryo.
// objective
On-brand decks people can make themselves, fast.
// challenge
Weekly all-hands and last-minute decks. Our presentation designer lost every Friday rebuilding slides, and people struggled with the PowerPoint template even after we simplified it.

02My part

// i made
Rebuilt the template in Slide Master and tested it. Then moved everything into bento/slides, an open-source editor; digitised our slide types — sales, all-hands and more; set up the AI agents myself.
// key decision
Stop making people learn the template. Give them typed slides and an agent that fills them.

03Craft

// design decision
Master slides grouped by meaning — covers, narrative, image layouts — a typology, not a pile of pictures.
// technical
Every deck carries a ready instruction for any agent — ChatGPT, Claude or Codex — to fill it with the user’s content on our masters.

04Result

// outcome
Used by half the company. All-hands decks now come together almost instantly: people bring the content, we run it through the tool. Next: hand it to Internal Comms.
// what i’d improve
Package it as a skill inside the LLM people already use, not a separate site. Keep adding templates and tuning on the slides the model handles worst.

Mercuryo at TOKEN2049

Designer, end to end · Singapore 2026 · from idea to print-ready files

Team jerseys with a hidden logo: sport stripes up close, the Mercuryo wordmark from across the hall.

01Brief

// project
Mercuryo at TOKEN2049 Singapore: two side events, team jerseys, table signs, a stand, keyrings, invitations, speaker slides.
// objective
Show Mercuryo as the seamless bridge between fiat and crypto.
// insight
“The best transition is the one you don’t notice.”

02My part

// role
Everything by hand, from idea to print-ready files — the team was busy with product launches.
// key decision
Hide the logo in the jersey’s stripes, so the brand reads at a distance without shouting.

03Craft

// design decision
Gradient as meaning: one colour flowing into another is the on/off ramp itself.
// feedback round
Restored the reading order — Mercuryo, then the message, then Singapore. Lighter compositions; brightness only as an accent.
// the jersey
A light optical illusion. I tested it at full scale on paper, stepping back and forth until the stripes resolved into the logo. Thin print, no heavy film — Singapore heat outside, air-conditioning inside. Black tees: screen print, separated by layers.

04Result

// outcome
The team was recognisable across the hall, and the jerseys were comfortable to wear all day.
// what i’d improve
Lock the list of deliverables earlier — the stand came and went. Merge the two side-event styles, bright and sporty, into one system. With more time, push the constructions and layouts further.

Bank AGM presentation

Designer · data storytelling · PowerPoint, Figma, Adobe

The Annual General Meeting deck of one of Eastern Europe’s largest banks: a large volume of financial data turned into one clear story.

01Brief

// challenge
Analyse and cross-check the numbers, build the narrative, and align every detail with the finance team and the CEO.

02My part

// process
Briefs arrive as sketches on paper or a few lines of text. I clarify the purpose — what story the speaker should walk out with — build the narrative, request missing data, ask questions, and only then design.

03Craft

// design decision
One key number per slide, with the trend beside it. One production workflow across PowerPoint, Figma and Adobe.
